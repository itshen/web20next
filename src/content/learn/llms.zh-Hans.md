## 一份简短的网站介绍

`llms.txt` 是一项提案：用 Markdown 文件向 Agent 简要介绍网站，并提供有用的资源链接。人也可以直接阅读它。参见 [llms.txt 提案](https://llmstxt.org)。

## Web 2.0 Next 如何使用它

本站的 [llms.txt — 面向 Agent](https://web20next.com/llms.txt) 介绍了项目，并链接到宣言、网站名录、贡献指南、资料格式和 PR 模板。文件统一使用英文，所有界面语言共用同一份内容。

当你让 Agent 来这里分享网站时，这份文件会指引它找到投稿说明。Agent 整理你确认的资料，发起 GitHub PR；经过维护者审核、合并并成功部署后，你的网站才会出现在名录中。读取文件并不会自动完成投稿。

## Agent 如何找到它

我们把文件放在 `/llms.txt`，并通过每个页面 HTML 头部的 `rel="describedby"` 链接声明它的位置。Agent 是否读取，取决于它本身及所用工具。发布这个文件并不保证被发现、被推荐或获得流量。

## 也为你的网站写一份介绍

你可以让 Agent 根据你愿意公开的资料准备一份 `llms.txt`：你是谁、在创作什么、在哪里能找到你的作品。保持简洁，并在网站变化时及时更新。它提供阅读指引，不代表授权 Agent 代你行动，也不能替代访问控制。
