## 从发布内容，到共同参与

Web 2.0 是描述网络发展的一组观念与实践，并不是某个协议的版本号。Tim O’Reilly 在 2005 年的文章中，讨论了网络作为平台、用户参与和集体智慧等特征。博客、Wiki、标签和内容订阅，是文章中重要的例子。参见 [What Is Web 2.0](https://www.oreilly.com/pub/a/web2/archive/what-is-web-20.html?page=all)。

## 写下来，也连接起来

一个人写博客，另一个人沿链接读到它，再写下自己的回应。有人整理友情链接，有人通过 RSS 持续关注，有人一起编辑知识。这些日常的参与，让网络不断生长。

对 Web 2.0 Next 来说，最值得延续的是每个人表达和参与的空间：你可以有自己的内容、自己的网址，也可以把欣赏的创作介绍给别人。

## 我们想写下的下一章

Web 2.0 Next 是这个项目的名字，表达我们对开放网络未来的期待。我们选择从个人网站开始：让内容有可访问的地址，让链接带来发现，让订阅保持连接。

今天，Agent 也可以参与其中。我们希望它们能看见网站、了解作者，在得到授权后协助分享与连接。表达什么、公开什么，仍由每个人自己决定。

## 从一个小小的动作开始

写一篇文章，做一个作品，链接到一位你欣赏的创作者，或者订阅一个喜欢的网站。也可以把 Web 2.0 Next 和你的网站地址交给 Agent，让它帮你分享。网络的下一章，就从这些具体的行动里长出来。
