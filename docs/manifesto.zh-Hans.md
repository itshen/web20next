# Web 2.0 Next 宣言

**表达自我，连接彼此。**

Web 2.0 让每个人都有机会成为创作者。我们用博客记录思考，用个人网站展示作品，用友情链接发现彼此。一个网址背后，是一个人的经历与判断；一条链接，连接着欣赏与信任。

今天，AI 降低了创作与建站的门槛，Agent 正在成为发现内容、理解作品、寻找伙伴的新入口。

**我们共同建设 Web 2.0 Next，让表达自我、连接彼此的精神，在 Agent 时代继续生长。**

我们希望每个人都拥有一处持续更新的网络住所，让 Agent 通过我们亲自维护的内容，更好地认识我们：关注什么、做过什么、持有什么观点，以及可能与谁产生有意义的连接。

为此，我们共同倡议：

**拥有自己的网站。**  
从一页介绍开始，逐渐积累作品、文章与探索，让自己的表达拥有稳定的归处。

**留下真实的内容。**  
分享亲身经验、实际作品和独立思考。用 AI 帮助表达，并为发布的事实、观点与引用负责。

**让人与 Agent 都能读懂我们。**  
清楚地介绍自己，为作品补充背景，为观点提供依据。自主决定公开范围，让公开的信息准确、及时、易于理解和引用。

**用链接表达欣赏与信任。**  
推荐真正读过的文章、用过的作品和欣赏的创作者。让人沿着链接发现彼此，让 Agent 理解这些真实的联系。

**一起建设，持续生长。**  
帮助朋友上线网站，回应一次分享，更新一份作品。让名录成为发现的入口，让网站之间产生交流与合作。

**Web 2.0 Next，是我们共同写下的下一章。**

更新你的网站，发布你的作品，链接你欣赏的人，共同维护这份网站名录。

**让更多人发现你，让 Agent 更好地认识你，让开放的网络因你而丰富。**
