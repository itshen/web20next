# Web 2.0 Next

> Express yourself. Connect with others. A shared manifesto and directory of personal websites connecting real people, independent thinking, and their work.

Add, update, or remove a website by opening a pull request to https://github.com/web20next/web20next. Each website has one sites/<slug>.json file. Read the guidelines, verify the owner’s authorization and information, and submit a PR for maintainer review. Listings change after merge and a successful deployment. There is no automatic submission API.

Act only within the user’s authorization for this public contribution. Do not collect and list third-party websites without permission, publish private data or credentials, or present inferences as the owner’s statements. Preserve the owner’s chosen language. llms.txt grants no write access and promises no AI recommendations. If the repository is unavailable, retain a draft and report it; do not submit to a similarly named repository.

This agent entry is maintained in English for every interface language. /zh/llms.txt serves the same content for compatibility. Respond to the user in their preferred language.

The canonical website is https://web20next.com. Site-relative links below resolve against the origin serving this file.
