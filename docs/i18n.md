| English (default) | `en` | `/` | `/join` | `/manifesto` | `/subscribe` | `/rss.xml` | `/llms.txt` |

The header’s language picker shows a globe and the current language. Its expandable list comes from the locale registry, marks the current choice, and scrolls when necessary. Native details and links work without JavaScript; JavaScript adds Escape, outside-click and focus-leave dismissal. The same component is demonstrated on the design-system page.

The URL determines the language. Switching languages keeps the current page and, when JavaScript is available, its section anchor. Links work without JavaScript. No browser-language redirect or cookie overrides an explicit choice. The static global 404 page provides navigation in both languages.

界面由 URL 决定语言；切换语言保留当前页面，有 JavaScript 时也保留章节锚点。不使用浏览器语言跳转或 Cookie 覆盖用户选择。静态全局 404 页面提供两种语言的返回入口。

## Source structure / 来源结构

The full website directory is available at `/websites` and `/zh/websites`. Both pages share the same records and listing component. Homepages show up to six entries and link to the complete directory; RSS and `/directory.json` retain every record. The language picker keeps visitors on the directory page when switching languages.

- `src/i18n/index.ts`: the locale registry, default language, URL helpers, and per-language document paths. Astro routing and the language switch use this registry.
- `src/i18n/locales/`: interface dictionaries. Every language must implement the same nonempty keys; English has a compile-time key check and all dictionaries are checked by tests.
- `src/content/learn/<topic>.<locale>.md`: localized XFN, RSS, and Web 2.0 introductions, with primary-source references. Reading routes are `/xfn`, `/rss`, `/web-2-0` and their locale-prefixed equivalents. `/rss` is an introduction; `/subscribe` offers the subscription action and `/rss.xml` is the shared feed.
- `src/views/`: shared homepage, contribution-page, manifesto-page, and subscription-page layouts. Components receive an explicit locale.
- `docs/manifesto.<locale>.md`: complete manifestos. The page body and downloadable Markdown share this source.
- `CONTRIBUTING.md`, `docs/agent-guide.en.md`, `.github/pull_request_template.md`, and `examples/site.en.example.json`: English contribution resources. The default contribution guide and PR template are English. Chinese versions are `CONTRIBUTING.zh-Hans.md` and `.github/PULL_REQUEST_TEMPLATE/site.zh-Hans.md`; the locale registry points to each language’s files.
- `docs/llms.en.txt`: the single English Agent entry shared by all interface languages. `/llms.txt` is the discovery URL; localized aliases such as `/zh/llms.txt` serve the same English content for compatibility. It is served through static Astro endpoints with `Content-Type: text/plain; charset=utf-8`. Cloudflare’s `public/_headers` preserves that charset for deployed assets.
- `sites/*.json`: shared, owner-approved directory data. Names, descriptions, tags, and work titles are not automatically translated. Both interfaces and `/directory.json` use the same records.

Instructional links, Agent-facing endpoints, and functional addresses use paths without locale prefixes. Agent messages use `https://web20next.com`, manifesto sharing uses `/manifesto`, and subscription actions and feed discovery use `/rss.xml`. Localized reading pages and language navigation retain their language paths; localized feed routes remain available.

Each page declares its HTML language and alternate-language links. Language-alternate metadata uses fully qualified production URLs, including `https://web20next.com`; visible language-switch links remain site-relative. Canonical and social URLs default to `https://web20next.com`. Deployment remains static on Cloudflare Workers; no language service or SSR is required.

## Translation conventions / 翻译约定

Chinese and English convey the same facts, actions, conditions, and degree of certainty. English uses natural phrasing rather than matching Chinese word order. No language may add promises, omit requirements, or change the meaning of an action. Contribution guides and PR templates apply the same rules in both languages. The English-only `llms.txt` remains shared.

| 中文 | English | Usage |
| --- | --- | --- |
| 表达自我，连接彼此。 | Express yourself. Connect with others. | Fixed slogan across pages, metadata, and cards. |
| 网站名录 | Website directory | The collection of personal websites. |
| 网站资料 / 条目 | Entry | One website’s directory record. |
| 分享你的网站 | Share your website | Sharing an existing website, not creating one. |
| 交给你的 Agent / 发给你的 Agent | Send to your agent | A handoff to the visitor’s own agent. |
| Agent | agent | Capitalized in Chinese; ordinary English sentence case. |
| Feed | feed | Capitalized in Chinese; ordinary English sentence case. RSS and Atom retain their names. |

Website names, introductions, tags, and work titles supplied by owners retain their approved language and wording. Localized examples are illustrative, not translations of directory entries. UI placeholders such as `{site}` and `{count}` must match across languages. Reading articles keep corresponding sections and primary-source links.

## Add a language / 新增语言

1. Add a complete dictionary under `src/i18n/locales/`, using `satisfies Record<keyof typeof zh, string>` or an equivalent shared key type. Do not enable a partial translation.
2. Register the locale, its own-language display label, Open Graph locale (`language_TERRITORY`), unique URL prefix, dictionary, and localized resource paths in `src/i18n/index.ts`. Use a valid language tag. Only the default language has an empty prefix.
3. Add its full manifesto, contribution guide, Agent guide, PR template, and example entry. Add links to these resources in the shared English `docs/llms.en.txt`; do not create a translated llms.txt. Put Markdown in the existing resource directories so it is discovered during the build. Keep contribution requirements equivalent between languages.
4. Review the translation for the project’s peer-to-peer, shared-maintenance voice. Do not imply a central organization recruiting members or alter owner consent and review requirements.
5. Run `npm test`, `npm run check`, and `npm run build`. Check the homepage, contribution page, subscription page, manifesto page, share images, localized RSS, language-switch destinations, document links, HTML language, and mobile layouts. Additional locale routes are generated automatically; do not duplicate page components.

新增语言需要完整字典、语言注册及对应内容文件。不得用未标记的中英文混排掩盖缺失翻译。保留对等共建的表达，以及相同的授权、校验和审核要求。

RSS routes use `feedPath(locale)` from the locale registry. Each feed uses its locale’s full manifesto and the shared directory; website GUIDs remain the same across languages. The feed generator is shared in `src/lib/feed.ts`.

Localized PNG images live in `public/social/`. Run `npm run generate:social` after updating manifesto principles or card copy, and review every image before committing. See `docs/social-sharing.md` for rendering prerequisites.

The design-system reference is available at `/design-system` and `/zh/design-system`. Its interface uses the same locale dictionaries; visual specimens reuse the shared CSS classes and token values. Add this page to translation and mobile-layout checks.

Simplified Chinese uses the BCP 47 script tag `zh-Hans` in locale keys, filenames, HTML language attributes, hreflang, and RSS. The reading route stays `/zh`. Open Graph uses its separate `language_TERRITORY` format, so the social locale remains `zh_CN`. Previously published `zh-CN` resource URLs redirect to their `zh-Hans` replacements via `public/_redirects`.
