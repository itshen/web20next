# 视觉与交互约定

本文件描述当前实现。样式的唯一来源是 `src/styles/global.css`，设计系统页 `/design-system`（中文 `/zh/design-system`）演示相同的变量与组件。页面通过 Astro 开发服务器或构建后的预览服务查看，不维护独立 HTML 副本。

## 视觉语言

延续个人网站、博客、友情链接与 RSS 的亲切感，以明亮、通透、有触感的页面回应 Agent 时代。个人网站与真实内容是主体，Agent 是阅读、理解与连接的参与者。视觉不暗示尚未实现的 AI 服务。

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 纸白 | `#FAFCFF` | 页面背景 |
| 链接蓝 | `#214FE8` | 品牌、链接、主要操作 |
| 墨蓝 | `#182745` | 正文和标题 |
| 天空蓝 | `#EAF2FF` | 插画与辅助区域 |
| 嫩芽绿 | `#D9F58B` | 连接提示、流程结果、分享卡片号召区域 |
| 石板蓝 | `#52627A` | 次级文字 |

具体色值、间距、圆角及字体以 CSS 变量为准。正文使用系统字体，品牌使用圆润的无衬线字体。正文左对齐，长文保持可读行宽。高光与投影集中于主要按钮、品牌插画和分享卡片，不覆盖所有内容块。

## 首页与阅读页面

- 首屏呈现固定标语、项目介绍、宣言与名录入口，以及个人网站窗口插画。桌面双栏，手机纵向排列。
- 主视觉之后展示完整宣言，外框突出阅读区域；标题、正文、后续链接上下排列。宣言不折叠，名录位于其后。标题区不重复标语；正文保留标语与全部内容，五条倡议使用绿色底的蓝色编号与独立小标题，结尾号召使用绿色底突出。首页只保留“独立阅读与分享”，Markdown 链接位于独立宣言页。
- 首页当前展示四位主理人及小互、姚金刚的网站，“更多网站”进入完整名录。该链接使用纯文字，不加箭头和下划线；悬停和键盘焦点仍有反馈。这个样式不替代正文超链接的全站样式。
- 独立宣言页提供完整正文、图片下载和页面地址复制。XFN、RSS、Web 2.0 介绍页为次级阅读入口，附原始资料来源，不挤入主导航。
- “如何运作”页说明实际投稿机制，流程图在宽屏横排、窄屏纵排；正文同时可读，不能把必要步骤只放进图片。

## Agent 消息区域

- 加入页提供可复制的完整消息，使用正式根域名，不带语言前缀或末尾斜线。
- “如何运作”链接靠近 Agent 引导，解释具体提交方式。
- 消息文字区域随内容和屏幕宽度自然增长，不用较大的固定高度制造空白，不截断消息。
- 复制按钮位于消息区域右下方；成功提示与手动复制提示在同一区域。复制不可用时选中完整消息，便于手动复制。

## 图标与控件

- “自己的网站，自己的表达”使用房屋图标。
- “用链接发现彼此”使用链环图标，链环中段较直，端部圆润。
- Agent 图标采用圆形外框和两枚纵向圆角眼睛。
- GitHub 与 RSS 入口保留对应图标；同组图标统一视觉尺寸，不与文字争夺层级。
- 语言选择显示地球图标与当前语言，展开完整语言列表；不将中英文按钮并排写死。
- 焦点使用清晰、轻量的外框，避免与按钮阴影叠出多重粗边框。动效以操作反馈为主，尊重减少动态效果偏好。

## 页脚

页脚当前由品牌区域和三个同级导航小节组成：

- 品牌区域：标志、标语、GitHub、RSS 订阅，以及 Next Token 词元之外的发起方署名和链接；署名下方保留蓝色“我 ♥ 个人网站 / I ♥ personal websites”徽章。
- 了解开放网络：Web 2.0、RSS、XFN 介绍，入口统一使用“什么是……？ / What is …?”。
- 面向 Agent / For agents：什么是 llms.txt？ / What is llms.txt?，链接到介绍页。
- 项目：如何运作、分享你的网站、设计系统。

不重复顶部的宣言与名录导航，只保留上述个人网站徽章，不堆放其他装饰徽章，不显示“视觉提案”“投稿渠道”等制作信息。llms.txt 介绍页提供统一英文 `/llms.txt` 文件入口。窄屏下三个小节在品牌下方分两列排列，保持简洁、完整、可操作。

## 验证范围

修改视觉时检查受影响页面的中英文及桌面、手机布局，重点关注较长英文、320px 窄屏、键盘焦点、复制反馈和内容是否被截断。影响分享卡片的文案或样式需重新生成并检查对应图片；生成方式见 [社交分享资源](social-sharing.md)。
